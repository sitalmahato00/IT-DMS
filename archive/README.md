This directory contains legacy and one-off files that were moved out of the project root to keep the repository clean.

Folders:
- `todos/` — notes and TODO files. Consider converting important TODOs into issues before deleting.
- `tests/` — ad-hoc test scripts that are not part of the test suite.
- `maintenance-scripts/` — one-off DB / migration / maintenance scripts.

If you need any of these files restored, they can be recovered from the commit in branch `chore/cleanup-legacy-files`.
